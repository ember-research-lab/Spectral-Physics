# Cosmology Module

Companion code for **Chapter 37: Cosmology** of
*Spectral Physics: A Unified Framework*.

## Overview

This module implements the spectral cosmology analyses from the book,
testing whether the cosmic web's graph Laplacian encodes dark energy,
filament structure, and early-universe physics.

### Key Results

| Analysis | Result | Script |
|----------|--------|--------|
| Universe eigenstate | 99.9996% ground state | `eigenstate.py` |
| Spectral floor | Lambda/H0^2 = 2.055 vs lambda_1/H0^2 = 2.0 (3% agreement) | `lambda_spectral_floor.py` |
| Density-lambda_1 | Corr(rho, lambda_1) = +0.950 | `density_lambda1_correlation.py` |
| Filament alignment | z = 8.1 at v_8, p < 0.001 | `eigenvector_alignment.py` |
| Hubble anticorrelation | Corr(lambda_1, H) = -0.183, p = 0.010 | `hubble_lambda1_anticorr.py` |
| Non-tautological | Partial r = 0.174, Delta R^2 = 3.0% | `non_tautological_test.py` |
| Attractor dynamics | S_cosmic +45.6% from z=10 to z=0 | `attractor_dynamics.py` |
| Early universe | 3 modes recoverable at z=10, 13 fixed points | `spectral_early_universe.py` |

## Running

### Tests (no external data needed)

```bash
uv run pytest cosmology/tests/ -v
```

All tests use synthetic data generated by `create_synthetic_universe()`.

### With CF4++ Data

Download `CF4pp_mean_std_grids.npz` (161 MB) from the
[Extragalactic Distance Database](https://edd.ifa.hawaii.edu/) and place
it at `cosmology/data/CF4pp_mean_std_grids.npz`. Then run individual scripts:

```bash
uv run python -m cosmology.cf4_spectral_test
uv run python -m cosmology.eigenvector_alignment
uv run python -m cosmology.hubble_lambda1_anticorr
```

### Standalone Scripts

Scripts that do not require CF4++ data:

```bash
uv run python -m cosmology.eigenstate
uv run python -m cosmology.lambda_spectral_floor
uv run python -m cosmology.attractor_dynamics
```

## Synthetic vs Real Data

The synthetic universe (`create_synthetic_universe()`) generates a density
field with a radial gradient and correlated velocities. It reproduces the
qualitative correlations of real data at reduced significance:

| Correlation | CF4++ (real) | Synthetic |
|-------------|-------------|-----------|
| Corr(rho, lambda_1) | +0.950 | ~+0.72 |
| Corr(lambda_1, v_r) | -0.183 | ~-0.74 |

The synthetic data validates the analysis pipeline. Quantitative results
are from CF4++ data only and are stored in `results/`.

## Dependencies

Core (in `pyproject.toml`): numpy, scipy, scikit-learn

Optional: `pip install astropy` for unit conversions (not required for tests).

## Caveats

1. The r=0.950 density-lambda_1 correlation is partially tautological.
   The non-tautological test (partial r=0.174) establishes residual
   predictive power.

2. The spectral early universe retrodiction is ill-conditioned (inverse
   heat kernel). Only the lowest 3 modes are recoverable at z=10.

3. Spectral time uses the convention tau_s = 3*H0^2*Delta_t, consistent
   with the book's derivation. The alternate convention (sqrt(3)*H0*Delta_t)
   gives different retrodiction depths.
